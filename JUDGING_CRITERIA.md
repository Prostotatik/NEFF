## Mandatory technical requirement

> **Mandatory: Gonka Router Integration (Required)**
>
> * All AI reasoning and verification logic **MUST** run on the Gonka Network via the official inference gateway ([`gonkarouter.io`](http://gonkarouter.io)). 所有 AI 推理与验证逻辑**必须**通过官方推理网关（`gonkarouter.io`）运行在 Gonka 网络上。
> * **Multi-Model Consensus**: You are encouraged to use at least two different models to "cross-verify" claims and ensure neutrality.
> * **Free Access**: During the hackathon, all participants will receive unlimited free token credits for development.

**Reading:** Gonka is a *hard requirement*, not a bonus. Multi-model is "encouraged" (scored bonus).
Therefore: 100% of inference must go through `api.gonkarouter.io`, and we use all 3 available models.

## Core Functionality (the four things the build must do)

> 1. **Claim Extraction**: Input a URL, tweet, or text snippet for verification.
> 2. **Decentralized Verification**: Use Gonka-hosted models to analyze the claim against real-time web data or internal knowledge bases.
> 3. **Truth Score & Reasoning**: Output a "Truth Score" (0-100%) and a detailed "Reasoning Trace" explaining the verdict.
> 4. **Transparency UI**: A dashboard showing the verification result and the specific Gonka Request IDs for each inference step.

## Developer Tips & Best Practices (explicit scoring signals)

> * **The "Neutrality" Prompt**: Design prompts that instruct the models to be objective and cite specific evidence for their conclusions.
> * **Cross-Model Comparison**: If two models disagree, how does your system handle the conflict? Building a "Consensus Logic" is a major plus.
> * **On-Chain Proof**: Always display the **Gonka Request ID** to prove that the "Truth" wasn't generated by a centralized server.

**Reading:** "Consensus Logic" is named as *a major plus* — the single largest discretionary scoring
lever in the document. Our whole differentiator lives here.

## Submission Criteria (hard deliverables)

> 1. **Live Demo URL**: A web app where users can paste a link/text and get a verification report.
> 2. **GitHub Repository**: Clean code with clear documentation on the Gonka Router integration.
> 3. **Video Pitch**: A 2-minute video showing a "Live Fact-Check" in action.
