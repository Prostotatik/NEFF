## Log

### Iteration 1 — orientation and first build

Baselines at 1536px: `evidence/visual/baseline-landing.png` (h 1093),
`evidence/visual/baseline-report.png` (h 3848). The baseline was a warm editorial treatment
(Fraunces serif, amber, bone-on-ink); the reference is neon `#00ffa3` on near-black with 3D orbital
scenes. Total re-skin, not a tune-up. Built `tools/shot.mjs` and `tools/crop.mjs`.

**Implementation approach chosen:** SVG, not WebGL and not raster. The reference's spheres are a
bright rim, a cage of great-circle filaments, and point lights — all vector primitives. SVG draws
them crisply at any size and animates on the compositor with CSS transforms, at no library cost; a
three.js scene would cost ~600KB plus one GPU context per orb, with four orbs on screen. Geometry is
generated by a seeded PRNG at module scope and **rounded to 3 decimals** — `Math.cos`/`sqrt` differ
in their last bits between Node and Chrome, which React reports as a hydration error.
